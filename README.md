Final Project README Question Answers.

1. What is the creative motivation / intended use of your project.
(Why did you make it? Who do you envision using it? What do you want the audience to experience?)


I created this as a fun way to reminisce about studying for exams while also creating a gameplay style. This game aims to look fun from the surface but then gets more annoying or agitating as you play, when one realises the multiple number of tasks they have to finish for their studies which will slowly feel like never ending as the stage goes by. At the same time at every stage of a game there is a mini test which gets harder and harder to complete for the final exam. However there is no logic in the tests just to confuse the player and make them feel hopeless  - like how we feel in exams. It is like doing english in a math exam where the questions are more of trying to confuse you then test your knowledge.
There is not much of guidance on how to play and one learns the game by exploring and using common game techniques like clicking and dragging.

Inspired by the weeks; play environment and net art, the games and interactive sites with buttons and links that we looked at in class , I wanted to build upon them further by creating my own game that is out of the arcade style and one more of a sketchy drawing look where you interact with it to explore the game.
Using conditional statements to control when the next scene transitions and comes. I also took inspiration of the pop up mini web pages of the hyperlinks to create the pop up reading pages for people to scroll through as if they are opening pages to study.
